# Липа

Сайт столярной мастерской «Липа» в Ярославле: столы, скамьи и полки на заказ из массива. Текст на русском, цены в рублях.

Стек: Next.js, TypeScript, Tailwind.

## Локальный запуск

```bash
npm install
npm run dev
```

Сервер слушает `0.0.0.0:43127`. Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

- `/` — мастерская, город, работы и вход в заказ
- `/raboty` — изделия, материалы, размеры и цены
- `/masterskaya` — как устроена работа
- `/zakaz` — порядок заказа, сроки и что прислать
- `/kontakty` — адрес, часы и телефон

## Скрипты

- `npm run dev` — разработка
- `npm run build` — статическая сборка в `out/`
- `npm run start` — продакшен на порту 43127
- `npm run lint` — ESLint

Секреты и внешние сервисы не нужны.
